## Getting Started

```bash
git clone https://github.com/rashaaad19/Kollekt.git
cd Kollekt
npm install
npm start   # or npm run dev, depending on the setup
```

> The app needs your own Firebase project and Firestore database. Add your Firebase configuration as described in the code.
